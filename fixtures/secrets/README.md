# Planted-secret corpus

Every value starting with `Planted` is a fake credential. The secrets
fixture tests (`crates/docmonk-mcp/tests/secrets.rs`) index this folder
and check that no read surface (search, evidence, explore, documents,
MCP) ever returns one: credentials inside indexed files are redacted
(ADR 0042), and `.netrc` and `*.tfstate` are never indexed at all.
Token formats (cloud keys, VCS tokens, JWTs) are generated by the test,
so no token-shaped string is committed.
